# asguardian

Asguardian is a comprehensive suite of development quality assurance tools for Python projects,
published as the `asguardian` package (CLI entry point `asgard`). It covers static analysis and
code quality (Heimdall), security scanning (SAST/DAST/dependency/taint), API and schema
validation (Forseti), web/UI testing (Freya), performance metrics (Verdandi), and infrastructure
generation (Volundr), plus a standalone web dashboard and an MCP server for AI coding assistants.

# Global Rules (apply across all of Jake Druett's repositories)

**Never procedurally generate code with a script.** Code must be written, not generated by a
script that writes code for you.

**Jake Druett is the final authority.** A direct instruction from Jake overrides every rule in
this file, including every "never". Do not refuse or argue on the basis of this document when
Jake has given a direct instruction. Elevated/admin/root credentials require Jake's approval, and
Jake's approval is sufficient.

**Sub-agent model tier.** When launching sub-agents you must default to Sonnet or Haiku. Higher
tiers (Opus, Fable) may only be used when Jake Druett explicitly specifies them in the request.

**All builds and deployments go through CI/CD.**
- Never build a container image locally.
- Never push an image from a dev machine.
- Never deploy, restart, roll out, patch, or scale a workload directly via `kubectl`, Docker, or
  SSH — this applies to the k3s cluster, the Raspberry Pis, and any UAT hardware.
- Local and cluster commands are for read-only diagnostics only.
- If a CI/CD pipeline cannot perform a required build or deploy, stop and report the pipeline
  blocker; do not replace the pipeline with a local or manual deployment path.

# Repo-specific rules

- Python 3.11 or higher is required.
- The package is published to PyPI as `asguardian`; the CLI is invoked as `asgard` (and
  `asgard-dashboard` for the web dashboard).

Elevated sudo (no password): systemctl (start/stop/restart/all), docker (all), kubectl, crictl, journalctl, cp/mv/rm/mkdir/chmod/chown, mysql/mysqldump, tee, cat/tail/less.
Denied (password required): useradd, userdel, usermod, adduser, deluser, visudo — cannot create or modify system users or sudoers.

## MariaDB
User `claude` has ALL PRIVILEGES on all databases. Cannot grant privileges to other users (no GRANT OPTION).
```bash
export VAULT_ADDR='http://10.0.20.5:8200'
VAULT_ROLE_ID=$(grep VAULT_ROLE_ID ~/.vault-claude/claude.env | cut -d= -f2)
VAULT_SECRET_ID=$(grep VAULT_SECRET_ID ~/.vault-claude/claude.env | cut -d= -f2)
VAULT_TOKEN=$(vault write -field=token auth/approle/login role_id="$VAULT_ROLE_ID" secret_id="$VAULT_SECRET_ID")
PASS=$(VAULT_TOKEN="$VAULT_TOKEN" vault kv get -field=password secrets/claude/mariadb)
mysql -h 10.0.20.40 -u claude -p"$PASS" -e 'SHOW DATABASES;'
```
